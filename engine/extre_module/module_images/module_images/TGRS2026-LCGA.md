# LCGA 模块总结

## 1. 动机

### 现有方法的问题

遥感图像中存在大量**曲线结构**（道路、河流、屋顶边缘等），这些结构的拓扑形态对 GIS 下游任务至关重要。然而现有方法存在以下不足：[2][3]

- **CNN 方法**：感受野有限，难以捕获沿曲线延伸的长程关联，需要极深的网络堆叠才能覆盖
- **标准 Transformer 注意力**：不对脊线区域显式重加权，注意力质量在脊线与非脊线区域无差别分配，导致边缘锯齿、细节模糊
- **纯窗口注意力**：虽然提升了效率，但上下文范围受限，且对几何结构完全不感知——注意力"泄漏"到纹理丰富但几何上不重要的区域

### 提出 LCGA 的目的

> 在局部窗口范围内，**显式强化脊线/曲线邻域的注意力聚焦**，同时在非脊线区域保持标准注意力的稳定性，从而改善曲线结构的连续性与对齐精度。[3][4]

---

## 2. 工作原理与核心思想

LCGA 的核心思想是：**用一个轻量可学习的曲率代理信号，对标准窗口注意力的 logits 进行乘法调制，再通过混合门控平衡曲率增强与稳定性。**[6][7][8]

### Step 1：计算曲率代理 $$\tilde{X}_c$$

```
输入窗口特征 X_in
    ↓
深度可分离 3×3 卷积（学习局部微分算子）
    ↓
MAC 跨通道均值聚合（抑制通道语义，保留结构显著性）
    ↓
LayerNorm 归一化（稳定跨场景尺度）
    ↓
输出：归一化曲率显著图 X̃_c（高响应处 = 曲率丰富区域）
```

> 深度可分离 $$3 \times 3$$ 卷积在小感受野内可近似模拟有向导数和二阶响应（如弯曲/转角），在特征场方向变化处激活强烈，相当于一组**可学习的曲率检测器**。[6][7]

---

### Step 2：计算标准窗口注意力 $$A_{Std}$$

将窗口展平为 $$M$$ 个 token，通过线性投影计算标准注意力：

$$L_{Std} = \frac{Q \otimes K^T}{\sqrt{C}}, \quad A_{Std} = \text{Softmax}(L_{Std})$$

$$A_{Std}$$ 作为**稳定基线分布**，保证非脊线区域的聚合行为不被破坏。[7]

---

### Step 3：曲率调制生成 $$A_{Curv}$$

将曲率代理 $$\tilde{X}_c$$ 以**乘法形式**注入 logits：

$$\tilde{L} = L_{Std} \odot (1 + \alpha \odot \tilde{X}_c)$$

$$A_{Curv} = \text{Softmax}(\tilde{L})$$

- 曲率显著处（$$\tilde{X}_c$$ 大）→ logits 被放大 → 注意力向脊线邻域集中
- 平坦区域（$$\tilde{X}_c$$ 小）→ 调制接近 1 → 行为接近标准注意力，保持稳定[8]

---

### Step 4：混合融合输出 $$A_{Blend}$$

$$A_{Blend} = \beta \odot A_{Std} + (1 - \beta) \odot A_{Curv}, \quad \beta \in [0,1]$$

- $$\beta$$ 是**可学习参数**，自适应平衡两种注意力
- 曲率证据强时 → $$\beta$$ 偏向 $$A_{Curv}$$，强化脊线聚焦
- 曲率证据弱时 → $$\beta$$ 偏向 $$A_{Std}$$，维持非脊线区域稳定性[8]

### 整体流程图

```
X_in ──→ 深度可分离3×3卷积 ──→ MAC ──→ LayerNorm ──→ X̃_c
  │                                                      │
  ├──→ Q/K/V 线性投影 ──→ A_Std (标准注意力)             │
  │                           │                          │
  │                           └──── 乘法调制 ←───────────┘
  │                                     │
  │                               A_Curv (曲率注意力)
  │                                     │
  └──────────────── 可学习混合 β ────────┘
                          │
                      A_Blend → 输出 X_out
```

## 3. 总结

| 维度 | 内容 |
|------|------|
| **解决的问题** | 标准窗口注意力对脊线/曲线区域无感知，导致边缘模糊和几何失真 |
| **核心创新** | 用轻量可学习曲率代理对注意力 logits 进行乘法调制，并通过混合门控兼顾脊线增强与非脊线稳定 |
| **设计优点** | 完全端到端学习，无需手工曲率算子；计算开销极小；与标准 Transformer 框架无缝集成 |
| **实验验证** | 消融实验表明，移除 LCGA 导致 PSNR 下降最大（−0.2148 dB），是 CGA 中贡献最显著的模块 |[13]

LCGA 的本质是：**用"在哪里弯曲"的几何信息告诉注意力机制"应该看哪里"**，以最小的计算代价将曲率保真度作为归纳偏置注入局部注意力，从而在遥感图像超分辨率中更好地重建道路、边界等曲线结构。[4][6]
