# FAAFusion 模块总结

---

## 1. 动机

### 现有方法的问题

传统 FPN（Feature Pyramid Network）在多尺度特征融合时，采用**简单的逐元素加法或拼接**来融合不同层级的特征。然而，这种做法忽略了一个关键问题：

- **高层特征**：具有强语义信息，感受野大，但经过多次下采样后空间细节模糊，方向信号**低频且粗糙**（例如只能判断物体大致水平，无法精确定向）
- **低层特征**：保留丰富的边缘、角点和纹理信息，携带**精确的高频方向线索**

当这两类特征被直接融合时，它们的**方向信号往往相互冲突**，在融合特征中引入噪声，从而降低角度预测的精度。 [1][3]

### 提出模块的目的

> 在融合之前，先将高层特征的主方向**显式对齐**到低层特征的主方向，从而确保跨尺度的方向语义一致性，减少融合噪声，提升角度预测精度。 [3][7]

---

## 2. 模块工作原理与核心思想

### 核心思想

利用**傅立叶频域分析**估计低层特征的主方向，然后将高层特征旋转至与低层特征方向一致，再进行融合。

### 工作流程

```
高层特征 Yˡ⁺¹  ──→ 上采样 ──→ 1×1卷积 ──→ unfold ──→ 局部块 pʰᵢ ──┐
                                                                    │
                                                         FAA旋转对齐  │
                                                                    ↓
低层特征 Xˡ    ──────────→ 1×1卷积 ──→ unfold ──→ 局部块 pˡᵢ ──→ FAE估计方向 θˡᵢ
                                                                    │
                                                                    ↓
                                              fold重建 ──→ Yˡ⁺¹ᵣₑ꜀ₒₙ
                                                                    │
                                                                    ↓
                              最终融合：Yˡ = Xˡ + Yˡ⁺¹ᵤ + Yˡ⁺¹ᵣₑ꜀ₒₙ
```

### 详细步骤说明

**Step 1：上采样与降维**

将高层特征 $$Y^{l+1}$$ 上采样至与低层特征 $$X^l$$ 相同的空间分辨率，并通过 $$1 \times 1$$ 卷积将两者的通道数统一压缩至中间维度 $$C_{mid}$$，以降低计算开销。 [9]

**Step 2：局部特征提取（unfold）**

对高层和低层特征分别使用 unfold 操作，提取每个空间位置 $$i$$ 对应的局部特征块：

$$\{p^h_i\}^N_{i=1} = \text{unfold}(\text{Conv}(Y^{l+1}_u))$$

$$\{p^l_i\}^N_{i=1} = \text{unfold}(\text{Conv}(X^l))$$

[9]

**Step 3：频域方向估计（FAE）**

对每个位置 $$i$$，利用傅立叶角度估计（FAE）从**低层局部特征**中估计其主方向：

$$\theta^l_i = \text{FAE}(p^l_i)$$

FAE 的具体过程为：对局部特征块做 2D 傅立叶变换 → 转换为极坐标 → 沿径向累加能量 → 取能量最大的角度作为主方向。 [7][8][9]

**Step 4：高层特征旋转对齐（FAA）**

以低层特征的主方向 $$\theta^l_i$$ 为目标，将对应位置的高层局部特征旋转对齐：

$$p^{rh}_i = \text{FAA}(p^h_i;\, \theta^l_i)$$

[9]

**Step 5：重建与融合**

对所有位置的对齐后高层特征块，使用 fold 操作重建特征图，并通过 $$1 \times 1$$ 卷积恢复通道维度，得到对齐后的高层特征 $$Y^{l+1}_{recon}$$。

最终融合公式为：

$$Y^l = X^l + Y^{l+1}_u + Y^{l+1}_{recon}$$

即：低层特征 + 上采样高层特征 + **方向对齐后的高层特征**，三者相加。 [10]

---

## 3. 总结

FAAFusion 的本质是在传统 FPN 融合的基础上，增加了一条**方向感知的对齐分支**。其创新点在于：

| 对比维度 | 传统 FPN | FAAFusion |
|----------|----------|-----------|
| 融合方式 | 直接逐元素相加 | 对齐后再相加 |
| 方向处理 | 忽略方向差异 | 显式对齐方向 |
| 特征一致性 | 跨尺度方向不一致 | 跨尺度方向一致 |
| 分析域 | 空间域 | **频域（傅立叶）** |

通过消融实验验证，FAAFusion 单独使用可将 LSKNet 在 DOTA-v1.0 上的 mAP 提升 **+0.42%**，证明了其在解决多尺度方向不一致问题上的有效性。 [17]

> **一句话概括**：FAAFusion 让高层特征在融合前"看齐"低层特征的方向，从根本上消除了跨尺度特征融合中的方向冲突问题。
