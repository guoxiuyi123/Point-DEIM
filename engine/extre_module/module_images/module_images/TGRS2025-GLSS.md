# GLSS模块总结

## 1. 动机

### 现有方法的问题
- **Transformer的计算效率问题**：Transformer虽然擅长通过自注意力机制提取全局上下文，但其计算复杂度是二次方的，导致计算效率低下[3][5]
- **Mamba的方向性局限**：Mamba作为状态空间模型虽然具有线性复杂度和强大的全局信息捕获能力，但其扫描操作沿特定方向顺序处理数据，可能无法充分建模遥感图像中各个方向上物体的复杂空间依赖关系[8]
- **局部信息的忽视**：Mamba在处理高分辨率特征时往往忽略局部语义信息，而在遥感图像分割任务中，局部特征信息与全局上下文同样重要[8]

### 提出模块的目的
设计GLSS（全局-局部状态空间）模块，旨在高效地捕获和整合全局与局部信息，同时通过引入八方向选择性扫描机制，增强模型对遥感场景中多方向复杂空间分布的建模能力[4][8]

## 2. 模块工作原理和核心思想

### 整体架构
GLSS模块采用**双分支架构**，分别处理全局和局部信息[8]：

#### **全局分支**
- 基于VSSBlock构建，主要包含：
  - 归一化层（LN）
  - 线性层（Linear）
  - 深度卷积（dwConv）
  - **八方向选择性扫描状态空间模型（8D-SSM）**[8]

- **八方向扫描机制（8D-SSM）**的核心设计[8]：
  - 将输入图像块沿**八个不同的遍历路径**展开成序列表示
  - 包括水平、垂直、对角线和反对角线方向，每个方向都有正向和反向两种扫描方式
  - 每个图像块序列通过独立的Mamba块并行处理
  - 最后重塑并合并结构生成输出特征图
  - 使每个像素能够从各个方向获取所有其他像素的信息，捕获复杂的空间关系

数学表示[8]：
```
X₁ = LN(8D-SSM(dwConv(Linear(LN(Xᵢₙ)))))
X_Global = Linear(X₁ ⊗ Linear(LN(Xᵢₙ))) + Xᵢₙ
```
其中⊗表示Hadamard乘积（逐元素乘法）

#### **局部分支**
- 包含1×1卷积块和两个并行的深度可分离卷积（3×3和5×5）[8]
- 使用不同卷积核尺寸捕获不同空间尺度的局部特征
- 采用深度可分离卷积在保持卷积特征表达能力的同时减少参数量

数学表示[8]：
```
X₃ₓ₃ = dwConv₃ₓ₃(Conv₁ₓ₁(Xᵢₙ))
X₅ₓ₅ = dwConv₅ₓ₅(Conv₁ₓ₁(Xᵢₙ))
X_Local = Concat(X₃ₓ₃, X₅ₓ₅)
```

#### **特征融合**
- 全局和局部特征沿通道维度拼接
- 通过1×1卷积恢复通道数以匹配输入通道，实现残差连接[8]

### 核心思想
1. **用Mamba替代Transformer**：利用Mamba的线性时间复杂度优势，在保持全局建模能力的同时提高计算效率[8]
2. **多方向全局建模**：通过八方向扫描机制，全面捕获遥感图像中任意方向的空间模式和依赖关系[8]
3. **全局-局部互补**：将Mamba的全局上下文建模能力与CNN的局部特征提取优势相结合，实现更全面的特征表示[8]

## 3. 总结

GLSS模块通过创新的双分支设计，成功地将Mamba的全局建模能力与CNN的局部特征提取优势相结合。其核心创新在于引入八方向选择性扫描机制，使模型能够从多个方向全面捕获遥感图像中复杂的空间依赖关系。实验结果验证了该模块的有效性：

- **八方向扫描的优势**：相较于单向、双向和四向扫描，八方向配置在Mean F1和mIoU上分别提升0.32%和0.52%[18]
- **性能提升**：在消融实验中，加入GLSS模块后，所有性能指标在三个数据集上均得到持续改善[17]
- **计算效率**：相比Transformer架构，GLSS模块在保持强大表达能力的同时显著降低了计算复杂度[3][8]

GLSS模块为遥感图像语义分割提供了一种高效且有效的全局-局部特征融合方案，特别适合处理具有复杂空间分布和多方向特征的遥感场景[8]。
