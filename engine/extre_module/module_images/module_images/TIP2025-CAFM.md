# CAFM 模块总结

---

## 1. 动机

### 现有方法的问题

在 DSMT 的精细像素细化阶段（Fine Pixel Refinement），网络采用了**双分支编码器**结构：[9]

- **第一分支**：处理来自粗特征提取阶段的输出 $$X_1$$，侧重于已经过初步处理的高层语义特征
- **第二分支**：处理粗特征提取阶段第二个 U-Net 的输出 $$X_2$$，经过 DWMAB 模块进一步强化

两个分支提取的特征来源不同、侧重不同，若仅用简单的**通道拼接（Concat）+ 1×1 卷积**进行融合，无法充分利用两路特征之间的互补关系，会造成信息的浪费与融合质量低下。

### 提出模块的目的

设计一个**跨注意力融合模块（CAFM）**，通过引入**通道注意力**与**空间注意力**机制，自适应地对两个分支的特征进行加权融合，从而：[9]
- ✅ 充分挖掘双分支特征之间的**互补信息**
- ✅ 提供**更丰富、更多样**的特征表示
- ✅ 使网络更好地适应复杂的高光谱数据模式

---

## 2. 工作原理与核心思想

### 核心思想：通道交叉注意力 + 空间注意力，两阶段自适应融合

CAFM 由两个子模块串联构成：**通道注意力交叉模块** 和 **空间注意力融合模块**。[9]

### 整体流程

```
两分支特征 Fc1, Fc2
        │
        ▼
  ┌─────────────────────┐
  │  阶段一：通道注意力交叉  │
  └─────────────────────┘
        │
        ▼
  ┌─────────────────────┐
  │  阶段二：空间注意力融合  │
  └─────────────────────┘
        │
        ▼
  Concat + 1×1 Conv → 最终融合输出
```

---

### 阶段一：通道注意力交叉模块

**目标**：让两个分支的特征相互感知对方的通道重要性，实现跨分支的通道级交互。

**Step 1**：对两分支特征 $$F_c \in \mathbb{R}^{H \times W \times N}$$ 分别进行全局最大池化和平均池化，送入两层 MLP，得到各自的**通道权重系数**：

$$W_c = \text{MLP}(\text{AvgPool}(F_c)) + \text{MLP}(\text{MaxPool}(F_c))$$

[10]

**Step 2**：将两分支的通道权重系数 $$W_{c1}$$ 与 $$W_{c2}$$ 做**矩阵外积**，构建**跨分支交叉矩阵**：

$$M_{cross} = W_{c1} \cdot W_{c2}^\top$$

[10]

> 💡 **核心思想**：交叉矩阵 $$M_{cross}$$ 编码了两个分支通道之间的**相互关联程度**，使每个分支的特征能够被对方的通道分布所调制，而非仅关注自身。

**Step 3**：用 Softmax 归一化后的交叉矩阵分别对两分支特征加权：

$$F_{s1} = \text{softmax}(M_{cross}) \cdot F_{c1}$$

$$F_{s2} = \text{softmax}(M_{cross}) \cdot F_{c2}$$

[10]

---

### 阶段二：空间注意力融合模块

**目标**：在通道交叉之后，进一步在**空间维度**上自适应地突出重要区域。

**Step 1**：对经过通道注意力处理后的特征 $$F_s$$，沿通道维度分别做最大池化与平均池化，拼接后送入两层 3×3 卷积，生成**空间权重系数**：

$$W_s = f^{3\times3}\left(\text{Concat}\left(\text{AvgPool}(F_s),\ \text{MaxPool}(F_s)\right)\right)$$

[10]

**Step 2**：将空间权重系数作用于原始输入特征（残差连接形式）：

$$F_1 = \text{softmax}(W_s) \cdot F_{c1} + F_{c1}$$

$$F_2 = \text{softmax}(W_s) \cdot F_{c2} + F_{c2}$$

[10]

> 💡 **残差设计**：保留原始特征的同时叠加空间注意力增强，避免信息损失，提升训练稳定性。

**Step 3**：将 $$F_1$$ 与 $$F_2$$ 沿通道维度拼接，经 1×1 卷积压缩，输出最终融合特征。

---

### 完整数据流示意

```
Fc1, Fc2
  │
  ├──[全局池化 + MLP]──► Wc1, Wc2
  │                          │
  │              Mcross = Wc1 · Wc2ᵀ
  │                          │
  ├──[softmax(Mcross) × Fc]──► Fs1, Fs2
  │
  ├──[MaxPool + AvgPool + Conv]──► Ws（空间权重）
  │
  ├──[softmax(Ws) × Fc1 + Fc1]──► F1
  ├──[softmax(Ws) × Fc2 + Fc2]──► F2
  │
  └──[Concat + 1×1 Conv]──► 最终输出
```

---

## 3. 总结

CAFM 的设计精髓在于**两阶段、跨分支的自适应注意力融合**：[9][10]

| 模块组成 | 作用 | 关键设计 |
|----------|------|----------|
| 通道注意力交叉模块 | 建模两分支通道间的互依赖关系 | 交叉矩阵 $$M_{cross}$$ 实现跨分支通道调制 |
| 空间注意力融合模块 | 在空间维度突出关键区域 | 残差连接保留原始信息 |

相比简单的 Concat + 1×1 Conv 融合方式，CAFM 通过**交叉矩阵**让两个分支相互感知，避免了特征融合时的信息冗余与丢失。消融实验中，去除第二分支（即 CAFM 所融合的对象）会导致 PSNR 下降 **1.30 dB**、SSIM 下降 **0.025**，间接证明了 CAFM 对双分支特征有效整合的重要价值。[17]
