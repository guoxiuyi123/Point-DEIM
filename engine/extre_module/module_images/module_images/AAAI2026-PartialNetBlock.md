# PartialNet v1 和 PartialNet v2 模块总结

## PartialNet Block v1

### 1. 动机

**现有方法的问题:**
- 传统的深度可分离卷积(DWConv)虽然能减少FLOPs,但存在内存访问频繁、并行度低的问题,导致推理速度慢[1]
- FasterNet等方法仅在部分通道上执行卷积操作,忽略了其他通道部分的潜在价值[3]
- 现有方法缺乏全局信息交互,特征提取能力受限[5]

**提出模块的目的:**
- 充分利用特征图所有通道的价值,而不是简单地让部分通道保持不变[3][5]
- 通过结合卷积和视觉注意力,在减少计算量的同时增强模型的表征能力[1][5]
- 实现局部归纳偏置和全局信息交互的平衡[5]

### 2. 模块工作原理和核心思想

**核心结构组成:**[7][10]
```
输入 → Conv1×1 → BN → ReLU → PAT_ch block → PAT_sp block → Conv1×1 → BN → 输出
         ↓_____________________________________________↑ (残差连接)
```

**两个关键子模块:**

**PAT_ch block (部分通道注意力块):**[6][7]
- 将输入特征通道按比例rp分割成两部分
- 一部分执行Conv3×3卷积操作(提取局部特征)
- 另一部分执行增强的高斯通道注意力:
  - 同时计算通道的均值(Mean)和标准差(Std)
  - 通过Conv1×2融合统计信息
  - 使用H-Sigmoid激活生成注意力权重
  - 进行全局空间信息交互
- 最后通过Concat操作融合两部分特征

**PAT_sp block (部分空间注意力块):**[6][7]
- 同样将特征通道分割成两部分
- 一部分执行Conv1×1操作(混合通道信息)
- 另一部分执行空间注意力:
  - 通过Conv1×1将通道信息压缩为单通道
  - 使用H-Sigmoid生成空间注意力图
  - 对特征进行空间加权
- 推理时可与MLP层的第二个Conv1×1融合,减少延迟影响[6]

**核心思想:**
- **并行处理**: 卷积和注意力在不同通道上并行计算,而非串行,提高GPU利用率[5]
- **互补性**: 卷积提供局部归纳偏置,注意力提供全局信息交互[5][6]
- **高效性**: 仅在部分通道上执行计算密集的注意力操作,降低element-wise乘法的开销[5]

### 3. 总结

PartialNet Block v1通过PAT_ch和PAT_sp的组合,在前三个阶段实现了局部特征提取和全局信息交互的有效平衡。相比FasterNet的纯卷积方法,v1模块在相似推理速度下显著提升了模型准确率(如PartialNet-T2比FasterNet-T2准确率提升1.3%)[12]。该模块证明了在部分通道上应用视觉注意力是可行且高效的[14]。

## PartialNet Block v2

### 1. 动机

**现有方法的问题:**
- PartialNet Block v1虽然有效,但感受野仍受限于卷积核大小
- 缺乏真正的全局建模能力,难以捕捉长距离依赖关系[6]
- 自注意力机制计算复杂度随特征图尺寸二次增长,难以在所有阶段使用[6]

**提出模块的目的:**
- 在网络深层扩展模型的全局感受野[6]
- 整合局部和全局特征,进一步提升模型准确率[3]
- 在保持推理速度的前提下引入自注意力机制[6]

### 2. 模块工作原理和核心思想

**核心结构组成:**[7][10]
```
输入 → Conv1×1 → BN → ReLU → PAT_sf block → PAT_sp block → Conv1×1 → BN → 输出
         (无残差连接,直接相加以保证训练稳定性)
```

**关键改进:**

**PAT_sf block (部分自注意力块):**[6][7]
- 替换v1中的PAT_ch block
- 将输入特征通道分割:
  - 一部分执行Conv3×3卷积(保持局部特征)
  - 另一部分执行自注意力机制:
    - 通过三个Conv1×1生成Query、Key、Value
    - 引入相对位置编码(RPE)增强位置信息[7]
    - 执行Softmax注意力计算
    - 使用LayerNorm进行归一化
- 通过Concat融合两部分特征

**使用策略:**
- **仅在第4阶段使用**: 此时特征图尺寸最小(h/32 × w/32),自注意力的二次复杂度可控[6][10]
- **修改残差连接方式**: 采用直接相加而非v1的跨层连接,确保训练稳定性[7][10]

**核心思想:**
- **阶段性设计**: 根据特征图尺寸选择性使用自注意力,平衡性能和效率[6]
- **局部-全局融合**: 通过Conv3×3和Self-Attention的组合,同时捕捉局部细节和全局上下文[6]
- **位置感知**: RPE的引入进一步增强了模型对空间关系的建模能力[7]

### 3. 总结

PartialNet Block v2专为网络最后阶段设计,通过引入PAT_sf block实现了局部卷积特征和全局自注意力特征的有效融合。实验表明,v2模块的加入使PartialNet-T2的Top-1准确率从78.9%提升至80.2%[14]。这种分阶段使用不同注意力机制的策略,在保持高推理速度的同时实现了更强的特征表达能力[10][14]。

## 两个模块的对比

| 特性 | PartialNet Block v1 | PartialNet Block v2 |
|------|-------------------|-------------------|
| **使用阶段** | Stage 1-3 (浅层和中层)[10] | Stage 4 (深层)[10] |
| **核心注意力** | PAT_ch (通道注意力)[7] | PAT_sf (自注意力)[7] |
| **感受野** | 局部(卷积核大小) | 全局(整个特征图)[6] |
| **计算复杂度** | 较低 | 较高(但特征图小)[6] |
| **残差连接** | 跨层连接[7] | 直接相加[7] |
| **设计目标** | 局部-全局平衡 | 全局建模增强[6] |

两个模块共同构成了PartialNet的层次化架构,实现了从局部到全局、从浅层到深层的渐进式特征学习策略[10]。
