# GLSS2D 模块总结

---

## 1. 动机

### 现有方法的问题

SS2D（二维选择性扫描）是VMamba中的核心模块，虽然能够有效捕获全局上下文信息，但将其应用于遥感图像时存在**关键缺陷**：

> SS2D在建立像素间全局关系时，会将二维图像展开为一维序列进行扫描，这一过程**破坏了原始相邻像素之间的空间邻接关系**，使得原本相邻的像素（如相邻的车辆像素）在序列中被迫分离，距离大幅增加。[10]

具体表现为：
- **局部细节提取不足**：扫描机制难以维持邻近token之间的近邻关系
- **局部与全局上下文整合不充分**：纯粹依赖SS2D无法同时兼顾局部空间细节[3][10]
- **边缘轮廓模糊**：缺乏对相邻像素依赖关系的建模，导致目标边界不清晰

### 提出模块的目的

设计GLSS2D模块，在**保留SS2D全局上下文捕获能力**的同时，通过引入局部分支**补充相邻像素的局部空间信息**，实现全局与局部特征的有效融合，从而提升遥感图像语义分割的精度。[3][9]

---

## 2. 模块工作原理与核心思想

### 整体结构

GLSS2D由**两条并行分支**组成，分别负责全局建模和局部细节提取，最终融合两者输出。[10][11]

```
输入特征 X' ∈ R^(H×W×2C)
        │
        ▼
   通道维度切分（Chunk）
   ┌────────────────────┐
   │                    │
   ▼                    ▼
X'₁ ∈ R^(H×W×C)    X'₂ ∈ R^(H×W×C)
   │                    │
   ▼                    ▼
【局部分支】          【全局分支】
Conv 1×1 ⊕ Conv 3×3   SS2D
   │                    │
   ▼                    ▼
Shift 移位窗口操作   Locality 局部前向反馈
   │                    │
   └────────┬───────────┘
            ▼
       Concat + LayerNorm
            ▼
    XFuse ∈ R^(H×W×2C)
```

---

### 核心组件详解

#### ① 局部分支（Local Branch）

**目标**：弥补SS2D对相邻像素依赖建模的不足，提取细粒度局部特征。[10][11]

- 使用**两个并行卷积层**（1×1 和 3×3）提取不同层次的局部特征：
  - **小核（1×1）**：捕获精细的点级特征
  - **大核（3×3）**：覆盖更广的局部区域信息
  - 两者通过**逐元素相加（⊕）** 融合，形成多层次局部特征 $$X_{local}$$

$$X_{local} = \text{Conv}_{1\times1}(X'_1) \oplus \text{Conv}_{3\times3}(X'_1)$$

#### ② 移位窗口机制（Shift Window Mechanism）

**目标**：增强局部特征的空间相关性，减少局部特征提取中的空间信息损失。[11]

操作流程（以垂直方向为例）：
1. 对局部特征进行**零填充**，防止信息丢失
2. 按窗口大小沿通道方向分组
3. 对每组特征进行**高度方向移位**（移位量为窗口大小的一半）
4. 拼接移位后的特征并通过 **Conv → BN → ReLU** 序列处理
5. 水平方向重复相同操作

> 移位操作**不涉及乘加运算**，计算复杂度极低，却能有效扩展局部特征的感受野。[11]

#### ③ 全局分支（Global Branch）

**目标**：利用SS2D的线性复杂度长距离依赖建模能力，捕获全局上下文。[10]

$$X_{global} = \text{SS2D}(X'_2)$$

SS2D通过四方向扫描展开→S6选择性状态空间处理→扫描合并，实现对全局语义的高效建模。[9]

#### ④ 局部性前向反馈模块（Locality Feedforward）

**目标**：为全局特征引入局部邻域信息，弥补SS2D对近邻像素建模不足的问题。[11]

结构为 **1×1 → 3×3 → 1×1** 的卷积块：
1. 对 $$X_{global}$$ 经过卷积块提取精细特征 $$\tilde{X}_{global}$$
2. 与原始 $$X_{global}$$ 进行**逐元素相加**融合

$$\tilde{X}_{global} = \text{Locality}(X_{global})$$

#### ⑤ 特征融合

将经过增强的局部特征和全局特征进行**拼接（Concat）+ 层归一化（LayerNorm）**，得到最终融合特征：

$$X_{Fuse} = \text{LN}\left(\text{Cat}\left(\text{Shift}(X_{local}),\ \text{Locality}(X_{global})\right)\right)$$

[11][12]

## 3. 总结

GLSS2D模块的核心思想是**"双分支互补，全局局部协同"**：

| 维度 | 内容 |
|------|------|
| **解决的问题** | SS2D扫描破坏相邻像素空间关系，局部细节提取不足 |
| **核心设计** | 全局分支（SS2D）+ 局部分支（多尺度卷积+移位窗口）并行处理 |
| **关键创新** | 移位窗口机制低成本扩展局部感受野；局部性前向反馈为全局特征注入局部信息 |
| **实际效果** | 有效改善边缘轮廓模糊、目标误识别及阴影干扰等问题 |
| **效率优势** | 移位操作无乘加运算，整体保持线性复杂度 |

[3][10][11][15][16]

GLSS2D通过让**全局分支"感知局部"、局部分支"具备全局视野"**，实现了两者的深度互补，是GLVMamba在遥感图像分割任务中取得优异性能的关键所在。[3][23]
