# Derf 模块总结

---

## 1. 动机

### 现有方法的问题

**正规化层（LayerNorm / RMSNorm / BatchNorm）的局限性：**
- 正规化层需要依赖激活统计量（均值、方差）进行计算，引入了额外的**内存访问和同步开销**。 [2]
- 对批次大小敏感，批次设置不当会导致**训练不稳定**。 [2]
- 其跨 token 或跨 channel 的统计计算使其难以并行化，存在**效率瓶颈**。 [2][3]

**DyT（Dynamic Tanh）的不足：**
- DyT 虽然证明了逐点函数可以替代正规化层，但其性能仅能**匹配**正规化层，无法超越。 [2][4]
- DyT 的函数形式（tanh）并非最优选择，设计空间尚未被充分探索。 [4]

### 提出 Derf 的目的

> 寻找一种**更优的逐点函数设计**，使其不依赖激活统计量，同时在性能上**全面超越**正规化层和 DyT，推动更强的 Normalization-Free Transformer 架构。 [1][2]

## 2. 模块工作原理与核心思想

### 2.1 设计原则：四大关键属性

研究者通过系统性实验，归纳出逐点函数作为正规化层替代时必须满足的四大属性： [4]

| 属性 | 含义 | 违反后果 |
|------|------|----------|
| **零中心性** | 输出在零附近对称平衡 | 偏移过大导致训练发散 |
| **有界性** | 输出被限制在有限范围内 | 激活爆炸、梯度不稳定 |
| **中心敏感性** | 在零附近对输入变化有响应 | 小信号无法传播，性能下降 |
| **单调性** | 输出随输入单调变化 | 梯度信号翻转，学习效率降低 |

[6][7][9][10][11]

### 2.2 函数形式

通过大规模函数搜索，**erf(x)** 在所有候选函数中表现最优，由此引入 Derf：

$$\text{Derf}(x) = \gamma \cdot \text{erf}(\alpha x + s) + \beta$$

其中 erf(x) 为标准高斯分布的累积分布函数（CDF）的缩放形式：

$$\text{erf}(x) = \frac{2}{\sqrt{\pi}} \int_0^x e^{-t^2} \, dt$$

**各参数的作用：**

| 参数 | 类型 | 初始值 | 作用 |
|------|------|--------|------|
| $$\alpha$$ | 可学习标量 | 0.5 | 对输入进行缩放，控制函数响应范围 |
| $$s$$ | 可学习标量 | 0 | 对输入进行位移，提升灵活性 |
| $$\gamma$$ | 可学习逐通道向量 | 全 1 | 仿射缩放输出，与正规化层保持一致 |
| $$\beta$$ | 可学习逐通道向量 | 全 0 | 仿射偏置输出，与正规化层保持一致 |

[14]

### 2.3 核心思想：隐式正则化

Derf 与正规化层的**本质区别**在于：

- **正规化层**：依赖 batch/token/channel 级别的激活统计量，动态调整变换，适应性强但易过拟合。
- **Derf**：仅依赖少量可学习标量参数（$$\alpha$$、$$s$$），对每个激活值**独立施加相同变换**，不依赖统计量。 [17][18]

这种有限的适应性天然起到**隐式正则化**的作用：

$$\text{训练损失：Norm} < \text{Derf} < \text{DyT}$$
$$\text{泛化性能：Derf} > \text{Norm} > \text{DyT（多数任务）}$$

> Derf 的性能提升**不来自更强的拟合能力，而来自更强的泛化能力**，同时相比 DyT 又保留了更高的拟合容量，实现了两者的最优平衡。 [17][18]

### 2.4 使用方式

Derf 以**一对一替换**的方式嵌入 Transformer：
- Pre-Attention 正规化层 → Derf
- Pre-FFN 正规化层 → Derf
- 最终正规化层 → Derf [14]

## 3. 总结

Derf 是一个**极简却高效**的逐点函数模块，其核心贡献体现在三个层面：

**① 理论层面**
通过对逐点函数四大关键属性（零中心性、有界性、中心敏感性、单调性）的系统分析，为 Normalization-Free Transformer 的设计提供了清晰的理论指导。 [21]

**② 设计层面**
基于 erf(x) 的 S 形曲线特性，引入可学习的缩放参数 $$\alpha$$ 和位移参数 $$s$$，在满足四大属性的同时，比 tanh（DyT）具备更优的函数形状，实现了更好的性能。 [14][18]

**③ 性能层面**
在视觉分类（ViT）、图像生成（DiT）、语音表示（wav2vec 2.0）、DNA 序列建模（HyenaDNA、Caduceus）等多模态、多任务场景下，Derf **一致超越** LayerNorm、RMSNorm 和 DyT，且形式简单，可直接替换现有架构中的正规化层，具有很强的实用价值。 [15][17][21]
