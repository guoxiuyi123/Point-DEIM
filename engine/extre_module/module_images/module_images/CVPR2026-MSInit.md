# MSInit 模块总结

## 1. 动机

### 现有方法的问题

现有纯卷积 STPL 模型（如 SimVP、TAU 等）依赖**固定、均匀的感受野**，无法自适应地捕捉空间异质的运动模式。[3][4]

具体而言，在 PFGNet 的设计中，核心的 PFG Block 需要在多个尺度之间进行**像素级的内容自适应融合**——即在每个空间位置，根据局部频率内容动态选择最合适的卷积尺度响应。

### 提出 MSInit 的目的

然而，这种自适应融合有一个前提：**模型必须首先能够访问覆盖低、中、高频的多样化多尺度响应**。[5]

如果没有这样的结构化初始化，PFG Block 将面临两难困境：

- 若直接在**均匀小核特征**上操作 → 缺乏长程上下文，频率覆盖不足
- 若触发**完整大核全尺度处理** → 计算开销过大，效率低下

因此，MSInit 作为一个**轻量级的多尺度预处理模块**被引入，目的是在进入 PFG Block 之前，高效地为后续频率引导门控构建稳定、多样的多尺度特征基础。[5]

## 2. 工作原理与核心思想

### 核心公式

对每个尺度 $$m \in \{1, \ldots, M\}$$，MSInit 执行如下变换：[5][6]

$$T_m(Z) = v_m * (h_m * Z) + d_m(Z) + Z$$

各项含义如下：

| 组成项 | 说明 |
|--------|------|
| $$h_m \in \mathbb{R}^{1 \times k_m}$$ | 水平方向一维卷积核 |
| $$v_m \in \mathbb{R}^{k_m \times 1}$$ | 垂直方向一维卷积核 |
| $$v_m * (h_m * Z)$$ | 可分离一维卷积，近似 $$k_m \times k_m$$ 的二维响应 |
| $$d_m(\cdot)$$（3×3 深度卷积） | 增强中频敏感性的补充分支 |
| $$+ Z$$（恒等项） | 残差连接，维持梯度流动 |

最终将各尺度输出通过 1×1 卷积投影后拼接：[5][6]

$$X = \text{Concat}\{{\text{Conv}_{1\times1}(T_m(Z))}\}_{m=1}^{M} \in \mathbb{R}^{C' \times H' \times W'}$$

实践中使用 $$k_m \in \{3, 5, 7\}$$ 三个尺度。

### 核心思想拆解

**① 可分离一维卷积近似大核**

将二维 $$k \times k$$ 卷积分解为 $$1 \times k$$ 与 $$k \times 1$$ 的串联，在保持大感受野的同时，将计算复杂度从 $$O(k^2)$$ 降至 $$O(2k)$$，实现**高效的多尺度特征提取**。[5][9]

**② 三分支覆盖不同频段**

- $$k_m = 3$$：小核 → 捕捉**高频**局部细节（边缘、纹理）
- $$k_m = 5$$：中核 → 捕捉**中频**结构信息（运动模式）
- $$k_m = 7$$：大核 → 捕捉**低频**全局上下文（背景、整体形状）

三者并行处理，确保后续 PFG Block 能从**全频段**的多尺度响应中进行自适应选择。

**③ 残差连接保障训练稳定性**

恒等项 $$+Z$$ 的引入保证了梯度的顺畅回传，避免多尺度特征提取过程中的梯度消失问题。

---

## 3. 总结

MSInit 是 PFGNet 中一个**轻量但不可或缺**的预处理模块。它的本质作用是：

> 在进入核心 PFG Block 之前，以极低的计算代价，为整个网络构建一个**结构化、多频段的特征基础**。

消融实验也直接验证了其重要性——移除 MSInit 后，所有评估指标均出现显著下降（TaxiBJ 上 MSE 从 0.2881 劣化至 0.3119）。[15]

MSInit 的设计体现了一种**分工协作**的思路：
- MSInit 负责"**广撒网**"——高效构建多尺度多频率特征
- PFG Block 负责"**精筛选**"——像素级自适应地融合最有价值的频率响应

两者相辅相成，共同支撑了 PFGNet 在效率与精度上的双重优势。
