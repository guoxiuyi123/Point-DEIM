# SparseMambaBlock 模块总结

---

## 1. 动机

### 现有方法的问题

在 UHD 图像修复任务中，解码器设计面临以下核心矛盾：

**① 全局建模与计算效率的矛盾**
- 基于 Transformer 的方法（如 LLFormer、UHDformer）虽具备全局感知能力，但自注意力机制的二次方复杂度在 UHD 分辨率下完全不可承受 [3][4]
- 基于 Mamba 的方法（如 MambaIR、Wave-Mamba）虽降低了复杂度，但解码器仍依赖逐像素扫描，在 UHD 图像上依然面临显存瓶颈 [3]

**② 全局上下文与局部细节的矛盾**
- 下采样类方法（如 UHDformer 的双分支策略）在低分辨率空间做全局建模，**丢失大量高频信息**，损害修复质量 [5]
- 纯聚类/压缩类方法在聚合特征时，**高频细节（边缘、纹理）容易被平滑掉**，单靠全局建模模块无法完整恢复 [3][8]

**③ 编解码器设计不对称性被忽视**
- 大多数方法在编码器和解码器中使用相同结构，导致编码器承担了不必要的全局建模计算开销，整体效率低下 [5]

### 提出当前 Decoder 设计的目的

> 核心目标：**在解码阶段同时实现高效全局上下文建模与高频细节保留，且不引入不可承受的计算代价。**

C2SSM 的解码器设计借鉴 MetaFormer 思想 [5]，通过将 CCSM 与 SCFM 有机整合进解码器，分别负责全局推理与细节补偿，形成功能互补的双路径结构，从根本上解决上述矛盾。

## 2. 模块工作原理与核心思想

### 整体架构定位

C2SSM 采用**非对称编解码器设计**：

```
编码器（轻量）：仅使用 FFN，专注特征提取，不承担全局建模
      ↓  Skip Connection（1×1 卷积）
瓶颈层：深层特征提取（N3=4 个 block）
      ↓
解码器（核心）：CCSM + SCFM + FFN，承担全局推理与细节恢复
      ↓
特征精炼阶段：进一步增强学习到的表征
      ↓
输出：将学习到的残差叠加到退化输入，得到修复图像
```

这种非对称设计将计算资源集中在解码器，最大化修复质量，同时避免编码器的冗余开销。[5]

---

### 解码器核心组成

解码器共包含 **N1=3 个层级**，每层级含 **N2=[2,4,4] 个基础 block**，每个 block 由以下三部分协同构成：

---

#### 组件一：CCSM（全局上下文建模）

负责解码器中的**全局长程依赖建模**，工作流程为：

$$F_d = \text{SiLU}(\text{DWConv}(\text{MLP}(F_{in})))$$

$$F_f = \text{Norm}(\text{SD}(\text{S6}(\text{FA}(F_d))))$$

$$F_{out} = F_f \cdot \text{SiLU}(\text{MLP}(F_{in}))$$

- **FA（特征聚合）**：将解码器当前层的特征压缩为 $$n$$ 个语义质心，捕获全局语义结构
- **S6（Mamba扫描）**：仅对质心进行选择性扫描，以极低代价建模质心间长程依赖
- **SD（分数扩散）**：基于全概率定律，将质心的全局权重反演回每个像素位置

在解码器中，CCSM 的作用尤为关键——解码阶段需要将压缩的语义信息**逐步还原为高分辨率特征图**，全局上下文的准确传递直接决定修复质量。[6][8]

---

#### 组件二：SCFM（局部细节补偿）

与 CCSM **并行运行**，专门补偿聚类过程中可能损失的高频细节：

$$W_s = \delta(\text{Conv}([\text{Max}(F_{in});\, \text{Mean}(F_{in})]))  \quad \text{（空间注意力）}$$

$$F_d = \text{Conv}(\text{ReLU}(\text{Conv}(F_{in})))$$

$$W_c = \delta(\text{Max}(F_d) + \text{Avg}(F_d))  \quad \text{（通道注意力）}$$

$$F_{out} = \text{Conv}(W_s \cdot F_{in}) + \text{Conv}(W_c \cdot F_{in})$$

- **空间分支**：通过最大值与均值的拼接，感知空间位置上的显著细节区域
- **通道分支**：通过通道维度的统计量，筛选信息量丰富的特征通道
- **双分支融合**：最大化输入输出特征之间的互信息，确保细节不被全局建模所淹没 [8]

---

#### 组件三：FFN（前馈网络）

在每个 block 中配合 CCSM 和 SCFM，负责**非线性特征变换**，增强解码器的表达能力。[5]

---

### 跳跃连接的作用

解码器通过 **1×1 卷积**将编码器对应层的特征融入解码器各层级：

$$F_{dec}^{(l)} = \text{Upsample}(F_{dec}^{(l+1)}) + \text{Conv}_{1\times1}(F_{enc}^{(l)})$$

这一设计确保编码器捕获的**浅层空间细节**（如边缘、纹理）能够直接传递到解码器，弥补深层特征中空间信息的损失。[5]

---

### CCSM 与 SCFM 的协同关系

```
输入特征 F_in
    │
    ├──→ CCSM ──→ 全局上下文权重（低频语义）
    │                        │
    └──→ SCFM ──→ 局部细节权重（高频细节）
                             │
                    Element-wise 融合
                             │
                        输出特征 F_out
```

两者形成**功能互补的双路径**：
- CCSM 负责"看大局"——建模跨区域的长程语义依赖
- SCFM 负责"顾细节"——保留局部高频纹理与边缘信息
- 消融实验证明：移除 CCSM 性能下降最大（PSNR 降至 35.87 dB），移除 SCFM 次之（39.05 dB），两者缺一不可 [14]

---

## 3. 总结

| 维度 | 内容 |
|------|------|
| **设计哲学** | 非对称架构，将计算资源集中于解码器 |
| **全局建模** | CCSM 以聚类质心为媒介，实现低代价全局上下文传递 |
| **细节保留** | SCFM 双分支注意力并行补偿高频信息损失 |
| **多尺度融合** | 跳跃连接保障浅层空间细节向解码器的直接传递 |
| **最终输出** | 残差学习方式叠加到退化输入，稳定训练并提升修复质量 |

C2SSM 解码器的核心设计思想是：**将全局推理与局部细节保留解耦，分别由专用模块承担，再通过并行融合实现两者的协同增强**。编码器负责轻量特征提取，解码器负责高质量特征重建，这种非对称分工使得整个网络在 UHD 全分辨率推理时既保持了出色的修复性能，又将计算开销控制在消费级硬件可承受的范围内。[5][13][15]
