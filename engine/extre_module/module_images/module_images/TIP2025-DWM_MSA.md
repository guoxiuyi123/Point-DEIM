# DWM-MSA 模块总结

---

## 1. 动机

### 现有方法的问题

现有的 Transformer 方法在 HSI 重建中面临两类核心矛盾：[3]

- **全局 Transformer vs. 局部 Transformer**
  - 全局 Transformer（如 ViT）能捕捉长距离依赖，但计算复杂度与图像尺寸呈**二次方**关系，对于高维高光谱数据而言计算代价极高
  - 局部 Transformer（如 Swin-Transformer）计算高效，但**无法有效捕捉长距离依赖**

- **多尺度信息缺失**：现有自注意力机制通常采用单一窗口尺寸，难以同时感知细粒度局部纹理与大范围结构模式，限制了模型对复杂场景的重建能力 [7]

### 提出模块的目的

设计一种新型自注意力机制，能够在**合理计算代价**下，**同时**满足以下三点需求：[4]
- ✅ 捕捉**局部信息**
- ✅ 捕捉**长距离依赖**
- ✅ 提取**多尺度特征**

## 2. 工作原理与核心思想

### 核心思想：分治 + 双窗口 + Shuffle

DWM-MSA 基于**分治策略（Divide-and-Conquer）**，将输入特征沿通道维度均分为四份，分别送入四个并行分支处理。[10][11]

### 整体流程

```
输入特征 X
    │
    ▼
线性投影 → Q, K, V
    │
    ▼
沿通道维度四等分
    │
    ├─── 分支1：窗口尺寸 S1×S1，标准 Window-MSA
    ├─── 分支2：窗口尺寸 S1×S1，先 Shuffle → Window-MSA → Unshuffle
    ├─── 分支3：窗口尺寸 S2×S2，标准 Window-MSA
    └─── 分支4：窗口尺寸 S2×S2，先 Shuffle → Window-MSA → Unshuffle
    │
    ▼
四分支结果 Concat → 线性层 → 输出 Y
```

### 各设计要素详解

#### ① 双窗口多尺度（Multi-Scale）
- 同时使用 **8×8** 和 **16×16** 两种窗口尺寸进行自注意力计算
- 小窗口捕捉**细粒度局部纹理**，大窗口感知**更大范围的结构信息**
- 实验验证：双窗口同时使用的重建质量优于任意单一窗口，且计算代价增加有限 [20]

#### ② Shuffle 操作（长距离依赖）
- 受 ShuffleNet 和 Half-Shuffle Transformer 启发 [10]
- 对 Q/K/V 进行 **Reshape 重排（Shuffle）**，打乱原有窗口内的 token 排列
- 使得原本位于**不同窗口**的 token 得以在同一窗口内计算注意力，从而在局部计算框架下**隐式实现跨窗口的长距离依赖**
- 计算完成后执行 **Unshuffle** 恢复原始空间排列

#### ③ 混合位置编码 CRPE（Positional Embedding）
- 在模块**入口**处使用 **CPE（条件位置编码）**：通过 3×3 深度可分离卷积动态生成位置编码，自适应捕捉空间局部性与相邻光谱带的上下文关系 [10]
- 在 **Q·K 点积之后**叠加 **RPE（相对位置编码）**：引入可学习参数，建模 token 间的相对距离关系
- 两者结合，同时建模**动态空间依赖**与**相对位置关系**，计算代价与单独使用 RPE 相当 [20][21]

#### ④ 完整的 DWMAB 块公式

$$X = \text{DwConv}(X_{in}) + X_{in}$$

$$Y = \text{DWM-MSA}(\text{Norm}(X)) + X$$

$$Z = \text{FFN}(\text{Norm}(Y)) + Y$$

[12]

## 3. 总结

DWM-MSA 的核心贡献在于通过**优雅的分治设计**，以接近局部 Transformer 的计算代价，同时实现了三种能力的统一：[4][18]

| 能力 | 实现机制 |
|------|----------|
| 局部信息捕捉 | 非重叠窗口内的 Window-MSA |
| 长距离依赖 | Shuffle 操作打破窗口边界 |
| 多尺度特征提取 | 双窗口尺寸（8×8 与 16×16）并行计算 |

消融实验表明，去除 DWM-MSA 会导致 PSNR 下降 **3.69 dB**、SSIM 下降 **0.046**，是整个 DSMT 框架中**贡献最显著的核心模块**。此外，将 DWM-MSA 移植到 MST、CST 等其他模型中同样带来了稳定的性能提升，证明了其良好的**通用性与可迁移性**。[17][18]
