# DEGConv模块总结

---

## 1. 动机

### 现有方法的问题

- **普通卷积的被动性**：常规卷积以固定方式处理所有输入信息，无法动态调节信息流，难以有效保留裂缝中的关键特征。[7]
- **复杂裂缝几何结构的挑战**：实际场景中，裂缝频繁向多个方向延伸并形成分支，存在大量交叉和重叠路径，模型难以准确追踪这些不规则的裂缝走向。[8]
- **裂缝区域占比低、背景干扰大**：裂缝图像中有效裂缝区域比例很低，背景噪声显著，需要对方向和边缘信息进行针对性增强。[14]

### 提出模块的目的

设计一个融合**多视角空间处理策略**与**方向先验知识**的模块，在不规则裂缝几何条件下增强模型的**边缘感知能力**，精确建模复杂裂缝结构，同时将计算开销控制在极低水平。[1][2][8]

---

## 2. 工作原理与核心思想

DEGConv 的整体流程如图 2(b) 所示，由以下四个组件依次协作完成：[4][8]

### （1）空间块重排（Rearrange）

对第 $$i$$ 层特征图 $$F_i \in \mathbb{R}^{C_i \times H_i \times W_i}$$，将其划分为 $$N$$ 个**不重叠的局部视图**，每个视图大小为 $$h_i \times w_i$$：

$$F_i = \{F_i^1, F_i^2, \dots, F_i^N\}, \quad N = \frac{H_i}{h_i} \times \frac{W_i}{w_i}$$

**目的**：将全局特征分解为多个独立的局部区域，为后续逐块进行方向分析提供结构化输入，同时降低单次处理的空间规模。[8]

### （2）方向嵌入生成（Direction Embedding Generation）

这是 DEGConv 最核心的创新部分，通过**无需监督信号的方向先验**构建方向嵌入：

**第一步：计算像素级梯度方向**

对每个局部视图 $$F_i^j$$ 沿通道维度取均值得到 $$\tilde{F}_i^j \in \mathbb{R}^{1 \times h_i \times w_i}$$，然后用 Sobel 算子计算水平梯度 $$dx$$ 和垂直梯度 $$dy$$，通过反正切函数获取每个像素的方向弧度值：

$$\theta = \arctan\left(\frac{dy}{dx}\right) \in [0, \pi]$$

[8]

**第二步：构建单元格方向直方图**

将视图进一步划分为 $$(cell_h, cell_w)$$ 大小的单元格，将弧度区间 $$[0, \pi]$$ 均匀分为 $$n$$ 个 bins。对每个单元格 $$C_{a,b}$$，统计各 bin 内的像素数量，并用 bin 的中心角度值加权：

$$index_{bin}(u,v) = \left\lfloor\frac{\theta(u,v)}{\pi / n}\right\rfloor$$

$$hist_{a,b}(k) = \sum_{(u,v) \in C_{a,b}} \mathbb{I}[index_{bin}(u,v) = k]$$

$$p_{a,b,k} = c_k \cdot \frac{hist_{a,b}(k)}{|C_{a,b}|}$$

其中 $$c_k = \frac{\pi}{2n} + k \cdot \frac{\pi}{n}$$ 为第 $$k$$ 个 bin 的中心弧度值，$$|C_{a,b}| = cell_h \times cell_w$$ 为单元格内像素总数。这种聚合方式能获得更紧凑的特征表示，同时减少个别异常像素的干扰。[8]

**第三步：生成方向嵌入向量**

将所有单元格的方向特征聚合为空间方向先验向量 $$p$$，再经过卷积和池化操作转化为一维方向嵌入：

$$f_p = \text{Conv}_{3\times3}(\text{Conv}_{1\times1}(p))$$

$$\epsilon = \text{avgpool}(\text{Norm}(\text{ReLU}(f_p))) \in \mathbb{R}^{C_i}$$

[8]

### （3）边缘卷积（Edge Convolution）

设计了一种**轻量级边缘卷积**结构，专门增强模型对裂缝纹理特征的感知：[8]

1. **逐点卷积**（$$1 \times 1$$）：将特征映射到低维空间，降低后续计算复杂度
2. **条形卷积**：
   - $$1 \times k$$ 卷积：提取**水平方向**裂缝特征
   - $$k \times 1$$ 卷积：提取**垂直方向**裂缝特征
3. **通道拼接 + 深度可分离卷积**：将两个方向的特征沿通道维度拼接，通过深度可分离卷积输出最终结果

### （4）门控机制（Gating）

通过门控动态调节信息流，将方向先验融入特征增强过程：[9]

$$g = \sigma_2\left(\text{EdgeConv}(F_i^j + \epsilon)\right)$$

$$F_i^{j'} = g \odot \text{EdgeConv}(F_i^j)$$

- **门控权重** $$g$$：由方向嵌入增强后的特征经 EdgeConv 和 sigmoid 函数生成
- **被门控特征**：原始特征经 EdgeConv 提取的边缘表示
- 两者通过**逐元素乘法**结合，实现对重要裂缝边缘信息的选择性保留

**后处理**：将各空间块的独立特征重排恢复原始空间结构，并引入额外的 EdgeConv 层消除块边界可能产生的对齐问题，最终得到优化后的特征表示 $$F_i'$$。[9]

## 3. 总结

| 维度 | 内容 |
|------|------|
| **核心思想** | 利用基于梯度方向的**方向先验**（而非依赖学习预测角度）构建具有几何可解释性的方向嵌入，通过门控机制动态增强不规则裂缝的边缘特征 [14] |
| **四组件协同** | Rearrange 提供结构化空间输入 → DEG 注入方向先验 → EdgeConv 提取多方向边缘特征 → Gating 动态选择关键信息，四者缺一不可 [19][20] |
| **极致轻量** | 整个模块仅增加 **0.08 GFLOPs** 计算量和 **0.14M** 参数量，几乎不增加模型负担 [12] |
| **消融实验验证** | 四个组件均对性能有贡献；其中 DEG（方向嵌入生成）带来最显著提升——在 DeepCrack 上 mIoU +0.36%，CamCrack789 上 +0.46% [19][20] |
| **优于替代方案** | 相比 ARConv 直接预测角度再计算方向嵌入的方式，本文基于方向先验的方法无需额外监督信号，方向嵌入更可靠，几何可解释性更强（DeepCrack 上 mIoU 91.51% vs. 91.06%）[14] |
| **超参数选择** | 默认 cell size 为 $$8 \times 8$$（过小易受噪声干扰），bins 数 $$n = 180$$（Crack500 因裂缝宽大、曲率小设为 36）[13][14][21] |
