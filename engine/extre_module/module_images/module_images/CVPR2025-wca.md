# WCA（小波增强交叉注意力）模块总结

---

## 1. 动机

### 现有方法的问题

现有的查询式方法主要聚焦于**空间域**的查询-特征交互，忽略了频率域信息的利用。对于工业表面缺陷检测而言，这存在两个核心问题：[3]

- **弱缺陷难以检测**：仅依赖空间信息难以捕捉细小、边缘模糊的弱缺陷特征
- **高频噪声干扰**：小波变换虽能分解出高频细节，但所得高频分量**缺乏语义信息**，可能包含背景噪声，直接使用会导致误检 [6]

### 提出模块的目的

在频率域中，高频分量包含丰富的边缘细节信息，是检测弱缺陷的突破口；低频分量则描述目标的基本结构。WCA 模块的目标是：**聚合有意义的高频与低频信息来精炼查询向量**，同时对高频分量进行噪声抑制，使查询更专注于缺陷细节。 [3][6]

---

## 2. 模块工作原理与核心思想

### Step 1：Haar 小波变换分解特征

给定图像特征 $$F_i \in \mathbb{R}^{H_i \times W_i \times D}$$，使用 **Haar 小波变换**将其分解为四个子带（分辨率减半）：[6][7]

$$F_{lfre} = F_{LL}$$

$$F_{hfre} = F_{LH} + F_{HL} + F_{HH}$$

- $$F_{LL}$$：低频信息，描述目标基本结构
- $$F_{LH}, F_{HL}, F_{HH}$$：分别为水平、垂直、对角方向的高频细节

### Step 2：多尺度通道权重调制（MSCM）

将高频与低频特征相加后，送入**多尺度上下文模块（MSCM）**，生成两类通道权重：[7]

$$W_{cg} = \text{Linear}(\delta(\text{Linear}(\text{GAP}(F_{hfre} + F_{lfre}))))$$

$$W_{cl} = \text{Linear}(\delta(\text{Linear}(F_{hfre} + F_{lfre})))$$

| 权重类型 | 作用范围 | 功能 |
|---|---|---|
| $$W_{cg}$$（全局通道权重） | 全局依赖 | 抑制特征通道层面的噪声 |
| $$W_{cl}$$（局部通道权重） | 局部依赖 | 抑制特征空间像素层面的噪声 |

### Step 3：高频分量调制与融合

融合两类权重，通过 Sigmoid 函数生成注意力权重，对高频分量进行**逐元素调制**，完成噪声抑制：[7]

$$F_{hfre}' = \sigma(W_{cg} + W_{cl}) \odot F_{hfre}$$

调制后的高频分量与低频特征合并，得到增强频率特征 $$F'_{fre}$$。

### Step 4：交叉注意力更新查询

以 $$F'_{fre}$$ 作为 Key 和 Value，通过交叉注意力层更新查询向量 $$Q_{in}$$：[7]

$$Q' = \text{Norm}(Q_{in} + \text{Attention}(Q_{in}, F'_{fre}))$$

### 核心思想示意

```
输入特征 Fi
    │
    ▼
Haar 小波变换
    ├──► 低频 F_lfre（结构信息）
    └──► 高频 F_hfre（边缘细节）
              │
              ▼
         MSCM 生成多尺度通道权重
         （全局 W_cg + 局部 W_cl）
              │
              ▼
         调制高频分量（噪声抑制）
              │
              ▼
         与低频融合 → F'_fre
              │
              ▼
         交叉注意力 → 更新查询 Q'
```

---

## 3. 总结

WCA 模块的核心贡献在于将**频率域信息**引入查询精炼过程。它通过 Haar 小波变换将图像特征分解为高低频分量，利用 MSCM 捕捉不同频率分量之间的**全局与局部通道依赖关系**，自适应地调制高频分量以抑制背景噪声，最终将增强后的频率特征用于更新查询向量。 [6][7]

消融实验表明，与标准交叉注意力（CA）相比，加入 WCA 后模型在 $$F_\beta^w$$ 指标上平均提升显著；与简单加法融合相比，调制融合策略在 $$F_\beta^w$$ 上平均提升 **0.69%**，验证了自适应调制策略的有效性。 [15]
