# WDAF模块总结

## 1. 动机

### 现有同尺度双输入融合方式的问题
在目标检测、语义分割或通用视觉骨干网络中，常常会遇到**两个空间尺度相同的特征图需要融合**的场景。虽然这两路特征分辨率一致，但它们在语义重心、边界细节、纹理响应和噪声分布上往往并不一致。如果仍然采用传统的静态融合方式，通常会面临以下问题：

- **直接相加（Add）过于固定**：默认两路特征在所有空间位置上的贡献近似一致，无法针对不同区域动态调整主次关系。
- **直接拼接（Concat）缺少显式域内选择机制**：虽然保留了更多原始信息，但只是将两路特征堆叠起来，后续卷积需要自行学习该保留什么、抑制什么，融合目标不够直接。
- **纯空域融合容易忽略频率结构差异**：很多检测任务中的边界、纹理、小目标细节，本质上更容易体现在高频响应中；而稳定语义与整体结构更容易体现在低频响应中。仅在原始域内建模，往往无法显式利用这种频率先验。
- **同尺度异构分支的有效信息类型不同**：一条分支可能更偏上下文语义，另一条分支可能更偏局部纹理与定位细节。如果不区分低频和高频信息，就容易出现语义压制细节或细节干扰语义的情况。

### 提出模块的目的
WDAF（Wavelet Dynamic Align Fusion）的目标，是在**不改变输入空间尺寸**的前提下，为两个同尺度输入建立一种“**原始域动态融合 + 小波域频率引导**”的双域协同机制。

它的核心出发点是：

- 先在原始域中保留 `DAF` 风格的动态融合主干；
- 再引入固定 Haar 小波分解，将每一路特征拆分为**低频分量**与**高频分量**；
- 分别在低频与高频空间中学习两路特征的动态权重；
- 将小波域得到的低频-高频融合结果作为**频率引导图**回注到原始域融合结果中；
- 最终输出同时兼顾语义稳定性和细节表达能力的融合特征。

这样可以让融合过程从“只在原始域内分配贡献”升级为“**原始域主导融合，频率域辅助校正**”。

## 2. 模块工作原理和核心思想

### 核心思想
WDAF可以概括为四个关键词：**对齐、分解、引导、协同**。

- **对齐（Align）**：先将两路输入映射到统一输出通道空间，保证后续空域和小波域建模都基于一致的特征表征。
- **分解（Wavelet Decomposition）**：利用固定 Haar 小波，将每一路特征拆成低频信息和高频信息，显式区分整体结构与局部细节。
- **引导（Frequency Guidance）**：在低频和高频两个子空间中分别生成动态权重，提炼出一张频率引导图。
- **协同（Dual-Domain Fusion）**：以原始域动态融合结果为主，以频率引导结果为辅，通过可学习系数完成最终双域协同。

### 整体流程

```text
输入: x1, x2
  │
  ├─ 1×1 Conv 对齐通道 ──> f1, f2
  │
  ├─ 原始域动态融合
  │    ├─ Concat(f1, f2)
  │    ├─ 3×3 Conv + Sigmoid
  │    ├─ Split ──> s1, s2
  │    └─ y_spatial = a1 * (f1 * s1) + a2 * (f2 * s2)
  │
  ├─ 小波域分解
  │    ├─ Haar(f1) ──> low1, high1
  │    └─ Haar(f2) ──> low2, high2
  │
  ├─ 低频动态建模
  │    ├─ Concat(low1, low2)
  │    ├─ 3×3 Conv + Sigmoid
  │    └─ low_fused = low1 * l1 + low2 * l2
  │
  ├─ 高频动态建模
  │    ├─ Concat(high1, high2)
  │    ├─ 3×3 Conv + Sigmoid
  │    └─ high_fused = high1 * h1 + high2 * h2
  │
  ├─ 小波引导图生成
  │    ├─ y_wave = b1 * low_fused + b2 * high_fused
  │    ├─ 3×3 Conv
  │    └─ 上采样回原尺度
  │
  └─ 最终融合
       out = Conv1x1(y_spatial + γ * y_wave)
```

其中：

- `s1`、`s2` 是原始域两路分支的动态权重；
- `l1`、`l2` 是低频分支的动态权重；
- `h1`、`h2` 是高频分支的动态权重；
- `a1`、`a2` 是原始域两路分支的全局平衡系数；
- `b1`、`b2` 是低频-高频两类频率信息的平衡系数；
- `γ` 是小波域引导强度的可学习缩放参数。

### 2.1 通道对齐
WDAF首先使用两个独立的 `1×1 Conv`：

```text
f1 = Conv1x1(x1)
f2 = Conv1x1(x2)
```

其作用不是简单压缩，而是将两路输入统一映射到相同的输出通道维度 `ouc`。这样做的直接意义在于：

- 解决两路输入通道数可能不同的问题；
- 保证原始域动态门控和小波域频率分解都在统一通道空间中进行；
- 使后续低频、高频以及最终输出映射具有统一的表征基准。

因此，WDAF要求**空间尺寸一致**，但对输入通道数并不苛刻。

### 2.2 原始域动态融合主干
在原始域部分，WDAF保留了 `DAF` 的核心思路，即先通过两路拼接特征生成动态权重，再对两路分支进行自适应重标定：

```text
m_spatial = Sigmoid(Conv3x3(Concat(f1, f2)))
s1, s2 = Split(m_spatial)
y_spatial = a1 * (f1 ⊙ s1) + a2 * (f2 ⊙ s2)
```

这样做的作用是：

- 在原始域内完成主体融合；
- 保留 `DAF` 对局部位置和通道响应的动态选择能力；
- 为后续小波域引导提供一个稳定的空域主干结果。

因此，WDAF并不是完全替换 `DAF`，而是在其基础上继续扩展。

### 2.3 小波域低频与高频分解
WDAF的关键创新在于引入固定 Haar 小波分解。对于每一路对齐后的特征 `f`，模块会执行：

```text
low, high = Haar(f)
```

其中：

- **low（低频分量）** 对应整体结构、轮廓和稳定语义信息；
- **high（高频分量）** 由多个高频子带聚合得到，更偏向边缘、纹理、细节与局部变化。

这一步的核心意义在于：

- 将原本混合在同一特征图中的“语义结构信息”和“细节边界信息”显式拆开；
- 让后续融合不再只问“哪一路更重要”，还能够进一步问“哪一种频率信息更重要”；
- 更适合目标检测中对小目标、边界和纹理敏感的场景。

此外，代码中还对奇数尺寸特征进行了补边处理，从而保证小波分解后仍然能够顺利恢复到可用的引导图尺度。

### 2.4 低频与高频的独立动态建模
得到两路特征的低频和高频响应后，WDAF分别对这两类信息做独立建模。

低频分支：

```text
m_low = Sigmoid(Conv3x3(Concat(low1, low2)))
l1, l2 = Split(m_low)
low_fused = low1 ⊙ l1 + low2 ⊙ l2
```

高频分支：

```text
m_high = Sigmoid(Conv3x3(Concat(high1, high2)))
h1, h2 = Split(m_high)
high_fused = high1 ⊙ h1 + high2 ⊙ h2
```

这样设计的原因是：

- 低频信息更偏向稳定语义和整体前景结构，应避免受到过多高频噪声干扰；
- 高频信息更偏向边界和细粒度纹理，应允许模型单独学习哪些细节应被保留、哪些应被抑制。

因此，WDAF并没有把所有频率信息混在一起处理，而是给低频和高频各自保留了一套动态选择机制。

### 2.5 小波引导图生成与双域协同
完成低频和高频的加权融合后，WDAF再通过可学习参数对两类频率信息进行平衡：

```text
y_wave = b1 * low_fused + b2 * high_fused
```

随后通过一个卷积层进行整合，并将其上采样回原始空间尺度：

```text
y_wave = Up(Conv3x3(y_wave))
```

得到的 `y_wave` 并不是直接替代原始域输出，而是作为一张**频率引导图**去补充原始域主干：

```text
out = Conv1x1(y_spatial + γ * y_wave)
```

这里的本质是：

- `y_spatial` 提供原始域的主体融合结果；
- `y_wave` 提供来自频率域的补充校正信息；
- `γ` 决定频率域在最终输出中的影响强度。

这样可以让模型在保持原始域稳定性的同时，更好地利用低频语义和高频细节两类不同性质的信息。

## 3. 解决了什么问题

### 3.1 解决纯空域融合难以显式利用频率先验的问题
许多同尺度融合模块仅在原始域内完成动态权重生成，虽然能够进行一定程度的内容感知融合，但它们往往无法显式区分低频语义信息和高频细节信息。

WDAF通过固定 Haar 小波分解，将这两类信息拆分后分别建模，从而让融合策略不再只基于“空间响应强弱”，而是能够利用更明确的频率先验。

### 3.2 解决语义结构与边界细节容易互相干扰的问题
在检测任务中，稳定的目标主体结构通常更偏低频，而边界、纹理、小目标细节通常更偏高频。如果把它们混在同一个动态门控中统一处理，往往会导致语义压制细节，或者细节噪声干扰语义判断。

WDAF通过低频分支和高频分支的独立建模，让两类信息分别学习自己的权重分配方式，从而减少它们之间的相互干扰。

### 3.3 解决同尺度异构分支协同不足的问题
同样尺度的两路输入常常来源不同，某一路更偏上下文语义，另一路更偏局部细节。若只采用简单相加或拼接，这种异构性很难被充分利用。

WDAF一方面保留原始域主干完成主体融合，另一方面再通过小波域分析补充低频与高频引导，从而使两路异构分支能够在双域空间中协同工作。

### 3.4 解决细粒度检测场景下有效信息被稀释的问题
对于小目标、遮挡目标或复杂背景中的边缘结构，很多关键线索本身就比较弱，容易在静态融合或单一空域门控中被淹没。

WDAF通过高频动态分支专门提取和筛选细节响应，再作为频率引导回注到原始域融合结果中，有助于保留那些容易被常规融合方式忽略的有效线索。

### 3.5 在保持可插拔性的同时提升融合表达能力
WDAF虽然引入了小波域建模，但其核心运算仍然主要由：

- 两个 `1×1 Conv` 对齐分支；
- 一个原始域动态门控；
- 一个固定 Haar 小波分解；
- 两个频率域动态门控；
- 一个引导图整合卷积；
- 一个最终 `1×1 Conv` 输出映射；

构成，并没有引入昂贵的全局注意力或复杂的频域重建模块。因此它在工程上仍然保持了较好的可插拔性，同时又具备更强的频率感知融合能力。

---

## 4. 总结

WDAF本质上是一种面向**两个同尺度输入特征图**的双域协同融合模块。与只在原始域内进行动态权重分配的传统方法不同，它通过引入固定 Haar 小波分解，使融合过程同时考虑：

- **原始域中的局部动态响应**；
- **小波域中的低频语义结构**；
- **小波域中的高频边界与细节信息**。

从结构上看，WDAF通过：

- **通道对齐** 保证两路输入处于统一表达空间；
- **原始域动态融合主干** 保留 `DAF` 的基础动态选择能力；
- **低频-高频分解与独立建模** 强化频率域感知；
- **频率引导回注** 提升最终输出对语义和细节的兼顾能力；
- **输出映射** 提升融合结果的可用性；

将同尺度双分支融合从“仅依赖原始域动态权重”升级为“**原始域主干 + 频率域引导**”的协同式融合方式。

因此，WDAF特别适合那些输入分辨率一致、但既需要稳定语义表达，又需要强化边界、纹理和细粒度目标响应的场景。
