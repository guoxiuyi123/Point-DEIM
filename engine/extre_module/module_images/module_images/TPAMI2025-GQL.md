# GQL模块总结

## 1. 动机

**现有方法的问题：**
- 虽然引入层次化多分支结构可以使物体检测器捕获丰富的多尺度特征，但它忽略了为不同尺度物体显式建模多尺度特征的重要性[7]
- 传统的层次化结构（如Res2Net）虽然能增强分支间特征的多样性，但会引入与目标物体无关的污染性空间信息，可能损害检测性能[2]

**提出模块的目的：**
- 为基础构建块提供跨阶段引导，使其能够动态聚合来自不同分支的不同粒度信息[7]
- 减少污染性空间信息的负面影响，提高特征提取的定位精度[7]
- 根据输入和所处阶段位置，动态平衡各分支的影响力[7]

## 2. 模块工作原理和核心思想

**核心思想：**
借鉴Transformer中注意力机制在给定查询Q和键K之间建立成对关系的有效性[7]，设计一个轻量级的全局查询学习策略。

**工作原理：**

1. **全局查询维护**：
   - 维护一个轻量级且可学习的全局查询 Q ∈ R^(N×c/2)，其中N是分支数量，c是查询的大小[7]
   - 该查询在不同阶段间传递，将全局空间信息转换到每个块中，以增加分支间的多样性[7]

2. **空间信息提取**：
   ```
   K = Linear(GAP(Y))
   ```
   - 通过全局平均池化(GAP)和线性层从当前块的空间信息Y中提取键K[7]

3. **动态权重分配**：
   ```
   Y' = S(Q × K^T) ⊙ Fms(Y)
   ```
   - 使用sigmoid函数S和元素级乘法⊙，根据前一阶段的信息和当前块所处的阶段位置，动态调整各分支的影响权重[7]
   - Fms表示用于增强分支间特征多样性的多尺度块[7]

4. **应用范围**：
   - 仅在backbone的第2、3、4阶段使用GQL，以在计算成本和有效性之间取得更好的权衡[7]
   - 通过GAP操作，全局查询非常轻量，使YOLO-MS的计算成本几乎可以忽略不计[7]

**有效性验证：**

- **定位精度提升**：在GT框内高激活特征（值>0.5）的面积比分析显示，GQL能使模型更准确地定位不同尺度的物体[11]
- **多尺度性能改善**：不同物体尺度的平均精度对比显示，GQL带来了明显的多尺度性能提升[11]
- **特征距离趋势**：训练过程中分支间特征距离与GQL注意力权重的趋势一致，进一步证明其有效性[11]
- **自适应分支调整**：在浅层阶段，小感受野的分支表现出更大的特征激活；在深层阶段则相反，表明GQL能自适应地重新安排各分支在相应阶段的作用[11]

## 3. 总结

GQL（全局查询学习）是一个轻量级且高效的注意力模块，通过维护一个可学习的全局查询在不同阶段间传递跨阶段空间信息。它能够根据输入特征和网络所处阶段动态调整各分支的权重，使得小感受野的分支在浅层阶段发挥更大作用（用于检测小物体），大感受野的分支在深层阶段发挥更大作用（用于检测大物体）。这种机制有效减少了污染性空间信息的影响，提升了特征提取的定位精度和多尺度表征能力，同时几乎不增加额外的计算开销[7][11]。实验证明，GQL显著提升了各尺度物体的检测性能，是YOLO-MS实现优异多尺度检测能力的关键组件之一。
