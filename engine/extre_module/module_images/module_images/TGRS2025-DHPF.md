# DHPF模块总结

## 一、动机

### 现有方法的问题：

1. **传统CNN的固有缺陷**：传统CNN方法在空间域中类似低通滤波器，擅长通过基于卷积核的聚合消除高频信息，但无法满足保留高频细节同时消除低频信息的需求[9][10]

2. **固定阈值方法的局限性**：现有频域学习方法通常依赖固定阈值来消除低频信息，这限制了它们处理具有多样化频率能量分布的红外小目标检测场景的能力[10]

3. **红外图像的特殊性**：许多红外图像包含大量低频背景区域（如路面、云层等缓慢变化的背景）和稀疏的高频区域（包括小目标和目标与背景之间的边缘）[9][10]

### 提出模块的目的：

设计一个动态高通滤波器(DHPF)模块，能够**动态自适应地逐步移除低频分量**，有效抑制缓慢变化的低频背景干扰，同时保留图像的高频细节信息[3][10]

## 二、模块工作原理和核心思想

### 2.1 整体架构

DHPF模块集成在频域分支的不同阶段，通过**分层渐进式**方式逐步移除低频信息[3][10]。如图2所示，在频域分支中，在不同阶段集成定制的DHPF，以逐步从图像中移除低频分量[10]。

### 2.2 详细工作流程（以第1阶段DHPF为例）

#### **步骤1：目标增强预处理**
- 输入红外图像IRI首先使用空域解码器生成的预测图$$P'_4$$进行初始滤波
- 计算公式：$$F_f^0 = \text{FFT}(\text{IRI} \odot P'_4 + \text{IRI})$$
- 作用：有效减少背景干扰，生成目标增强图像，然后通过FFT转换到频域得到频率特征图$$F_f^0$$[10]

#### **步骤2：频率能量计算**
- 计算频率特征图$$F_f^0$$的总能量：
  $$E_C = \sum_{u=1}^{H}\sum_{v=1}^{W}|F_f^0(u,v)|^2$$
- 其中$$(u,v)$$表示频率特征图中的像素坐标，$$F_f^0(u,v)$$是像素$$(u,v)$$处的幅值，$$E_C$$表示图像的总频率能量[10]

#### **步骤3：动态滤波掩码生成**
- 根据预设的能量移除比例$$\lambda_i$$计算滤波掩码：
  $$E_{\text{removed}} = \sum_{u=u_0-d}^{u_0+d}\sum_{v=v_0-d}^{v_0+d}|F_f^0(u,v)|^2 \leq \lambda_1 \times E_C$$
  
- 其中：
  - $$E_{\text{removed}}$$表示在该DHPF阶段需要抑制的低频能量
  - $$(u_0, v_0)$$表示特征图的中心像素坐标
  - $$\lambda_1$$是预设的能量移除比例
  - $$d$$是满足上述条件的最大半径值[10][11]

- 生成动态滤波掩码：
  $$\text{Mask}(u,v) = \begin{cases} 0, & \text{if } |u-u_0| \leq d, |v-v_0| \leq d \\ 1, & \text{otherwise} \end{cases}$$[11]

#### **步骤4：目标增强输出**
- 应用掩码并通过逆FFT返回空间域：
  $$F_{\lambda_1} = \text{iFFT}(\text{Mask} \odot F_f^0)$$
- $$F_{\lambda_1}$$即为第1阶段DHPF模块的输出[11]

### 2.3 核心思想

#### **1. 渐进式能量过滤策略**

- **四阶段递减设计**：四个DHPF阶段使用递减的能量过滤比例：
  $$\lambda = [\lambda_1, \lambda_2, \lambda_3, \lambda_4] = [0.8, 0.4, 0.2, 0.1]$$[11]

- **设计原理**：
  - 初始红外图像包含丰富的低频信息
  - 随着解码器过渡到浅层，其预测图中的低频背景量逐渐减少
  - 因此逐步降低能量过滤比例，避免过度滤除目标信息[11]

- **渐进效果**：
  - 随着$$\lambda$$在不同DHPF模块中减小，低频信息逐渐减少
  - 大面积低频背景信息和高频边缘背景区域被逐步抑制
  - 如图4(b)(c)所示，随着$$\lambda$$减小，背景被逐步抑制而小目标得以保留[11]

#### **2. 动态自适应滤波机制**

- **非固定参数**：掩码半径参数$$d$$不是固定值，而是根据以下因素动态确定：
  - 当前输入图像的频率能量$$E_C$$
  - 预设的能量移除比例$$\lambda$$[20]

- **自适应特性**：
  - 在不同DHPF阶段，$$d$$基于不同输入图像和不同预设$$\lambda$$自适应变化
  - 例如：给定$$\lambda = [0.8, 0.4, 0.2, 0.1]$$时，不同阶段获得的掩码半径为$$d = [29, 6, 2, 8]$$
  - $$d$$值总体趋于随$$\lambda$$减小而减小，但不一定严格递减
  - 如$$d_4$$增加到8，是因为$$F_{\lambda_3=0.2}$$（第4阶段DHPF的输入图像）可能包含大量已减少的低频能量，因此需要更大的掩码半径$$d$$来满足预设的$$\lambda_4=0.1$$[20][21]

- **优势**：这进一步证明了DHPF模块在滤除低频信息方面的动态性和自适应性[21]

#### **3. 频域全局视角**

- 红外图像表现出多样化的频谱能量分布，而CNN和Transformer主要在空间域操作，缺乏频率感知视角来区分不同模式[3][5]
- DHPF通过频域处理提供全局频谱视角，能够更有效地区分目标和背景的频率特征[5][6]

## 三、总结

DHPF模块通过以下三个关键创新实现了有效的红外小目标检测：

### 1. **动态自适应滤波**
- 摒弃传统的固定阈值方法，根据图像内容动态调整滤波掩码
- 提供更具适应性和上下文感知的背景噪声抑制能力[6][10]

### 2. **渐进式低频抑制**
- 通过四阶段递减的能量过滤比例（0.8→0.4→0.2→0.1）
- 在不干扰目标信息的情况下，逐步过滤缓慢变化的丰富低频背景
- 既能有效抑制低频背景，又能保留高频目标细节[11][20]

### 3. **频域全局建模**
- 利用频域的全局特性，有效区分红外图像中多样化的频谱能量分布模式
- 弥补CNN和Transformer在空域操作的局限性[3][5]

### 实验验证效果：

- **定量结果**：消融实验表明，DHPF模块在IRSTD-1k数据集上使IoU提升5.65%，Pd提升3.74%，并有效降低误报率Fa[16][17]

- **定性结果**：视觉示例证明该模块能够：
  - 准确检测低频背景中的小目标
  - 有效抑制复杂背景干扰
  - 随着能量过滤比例增加，更多背景信息被过滤，模型更准确地检测小目标[19][20]

- **最终融合**：最终预测图P通过融合空域预测图$$P_0$$和频域第4阶段DHPF生成的特征图$$F_{\lambda_4}$$得到，有效抑制背景区域同时保留小目标区域[11][12]
