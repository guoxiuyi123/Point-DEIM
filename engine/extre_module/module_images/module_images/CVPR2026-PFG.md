# PFG 模块总结

## 1. 动机

### 现有方法的问题

**① 纯卷积模型感受野固定**

现有纯卷积 STPL 模型依赖固定、均匀的感受野，无法根据空间位置的局部内容动态调整——对所有像素一视同仁，既无法为纹理丰富区域提供更宽的整合范围，也无法对均匀背景区域抑制冗余的低频响应。[3][4]

**② 简单扩大卷积核并不够**

虽然大核卷积（RepLKNet、SLaK 等）可以近似全局上下文，但它们对所有像素施加**统一的大核**，忽略了最优感受野大小因像素而异的事实：[3][5]

- 纹理丰富区域 → 需要**宽感受野**进行广泛整合
- 均匀平滑区域 → 需要**抑制冗余低频响应**，避免浪费计算

**③ 缺乏频率引导的自适应机制**

现有频域方法（AFNO、DCFormer 等）需要显式变换到频域，引入额外计算开销；通道级或频带级门控无法适应局部纹理变化；没有任何已有工作将**生物中心-周邊机制、频域滤波和自适应大核融合**统一在纯卷积 STPL 框架中。[5]

### 提出 PFG 的目的

受生物视觉系统中**中心-周边拮抗感受野**的启发——其数学本质是一种空间带通滤波器，选择性响应中频变化（边缘、纹理），同时抑制低频（均匀背景）和高频（噪声）——PFG 模块旨在：[1][3]

> 在**空间域**内，以像素级频率线索为引导，动态调制多尺度大核感受野，形成自适应带通滤波器，无需递归或注意力机制即可实现结构感知的时空建模。

## 2. 工作原理与核心思想

PFG Block 的整体流程可分为以下四个步骤：

### Step 1：提取像素级频率描述子

从输入特征 $$X \in \mathbb{R}^{C' \times H' \times W'}$$ 出发，通过固定深度卷积提取三种局部频谱线索，并经通道平均后拼接为频率描述子 $$F \in \mathbb{R}^{3 \times H' \times W'}$$：[6][7]

$$f_1 = \sqrt{(G_x * X)^2 + (G_y * X)^2}, \quad f_2 = |L * X|, \quad f_3 = \mathbb{E}_{3\times3}[X^2] - \mathbb{E}_{3\times3}[X]^2$$

| 线索 | 算子 | 捕捉的信息 |
|------|------|-----------|
| $$f_1$$ | Sobel 梯度幅值 | 边缘强度（高频边界） |
| $$f_2$$ | Laplacian 响应 | 曲率变化（二阶频率特征） |
| $$f_3$$ | 局部方差 | 纹理丰富程度（局部频率能量） |

三者互补，共同描述每个像素的局部频率状态，消融实验证明缺少任一线索均会导致性能下降。[16]

### Step 2：生成像素级多尺度门控权重

将频率描述子 $$F$$ 经轻量 1×1 卷积映射为每像素、每尺度的门控 logits，再经 softmax 归一化得到自适应选择权重：[6][7]

$$Z_g = W_g * F + b_g \in \mathbb{R}^{K \times H' \times W'}$$

$$\alpha_k(h, w) = \frac{\exp(Z_{g,k}(h,w))}{\sum_{j=1}^{K} \exp(Z_{g,j}(h,w))}, \quad k \in K$$

其中 $$\sum_k \alpha_k(h,w) = 1$$，确保每个像素在多个尺度之间进行**凸组合式的自适应选择**。

### Step 3：多尺度周边响应 + 可学习中心抑制

对每个尺度 $$k \in K = \{9, 15, 31\}$$，大核卷积被分解为可分离一维卷积以降低计算量，并施加可学习的中心抑制：[7][8][9]

$$P_k = v_k * (h_k * X) \in \mathbb{R}^{C' \times H' \times W'}$$

$$Y_k = P_k - \tanh(\beta_k) \odot (C * X)$$

**关键设计解析：**

- $$P_k$$：大核（周边）卷积响应，捕捉宽范围上下文
- $$C * X$$：3×3 深度卷积提取的中心局部响应
- $$\tanh(\beta_k) \in (-1, 1)$$：可学习的通道级抑制系数，支持**双向调制**

$$\tanh$$ 的选择至关重要——值域 $$(-1,1)$$ 允许正负两个方向的调制，使模型既能**抑制**中心冗余响应，也能**增强**中心有益响应，而 sigmoid 只能单向抑制，表达能力更弱。[16]

**频域理论解释：**

大核减去小核在频域上形成**环形带通滤波器**：[8][9]

$$H_k(\omega) = H_{L_k}(\omega) - \beta_k H_S(\omega)$$

$$H_k(\omega) > 0, \quad \omega \in \Omega_m = \{\omega : r_1 < \|\omega\| < r_2\}$$

- 抑制低频（$$\|\omega\| < r_1$$）：静态均匀背景
- 放大中频（$$r_1 < \|\omega\| < r_2$$）：运动边缘、纹理结构
- 衰减高频（$$\|\omega\| > r_2$$）：随机噪声

这与视网膜神经节细胞的 **Difference of Gaussians（DoG）** 模型在数学上高度一致。[3][26][27]

### Step 4：自适应多尺度融合输出

将门控权重与各尺度周边响应做逐像素加权求和，得到最终 PFG 输出：[7][8]

$$\text{PFG}(X) = \sum_{k \in K} \alpha_k \odot Y_k$$

随后经过 **GLU 风格通道混合**（扩展通道后分裂为 U、V 两路，门控融合）以及 **GRN 正规化** 和 **LayerScale**，完成完整的 PFG Block 处理。[9]

### 整体数据流示意

```
输入 X
  │
  ├──→ [频率描述子提取] f1(梯度), f2(Laplacian), f3(方差)
  │         │
  │         └──→ 1×1 Conv → Softmax → 门控权重 α_k (像素级)
  │
  ├──→ [多尺度大核卷积] P_k (k=9,15,31) 可分离1D分解
  │         │
  │         └──→ 减去 tanh(β_k) × 中心响应 → Y_k
  │
  └──→ 加权融合 Σ α_k ⊙ Y_k → GLU通道混合 → 输出
```

## 3. 总结

PFG 模块是 PFGNet 的**核心创新**，其本质是在纯卷积框架内实现了一种**生物启发的、频率引导的、像素自适应的空间带通滤波机制**。

其设计的精妙之处体现在三个层面的协同：

| 层面 | 机制 | 效果 |
|------|------|------|
| **感知层** | 三种频率线索（梯度/Laplacian/方差）| 精准感知每像素的局部频率状态 |
| **选择层** | 像素级 softmax 多尺度门控 | 动态分配不同区域的最优感受野 |
| **滤波层** | 可学习中心抑制 + 大核周边响应 | 形成自适应环形带通滤波器 |

消融实验全面验证了各组件的必要性：MSInit + softmax 融合 + $$K=\{9,15,31\}$$ + 可学习 $$\beta$$（tanh 激活）+ 三种频率线索的完整配置，在 TaxiBJ 和 KTH 等基准上均取得最优结果。[15][16]

PFG 模块最终使 PFGNet 在**无需递归、无需注意力**的前提下，以极少的参数和计算量实现了媲美甚至超越循环模型的时空预测精度，为高效预测视觉系统的设计提供了新的范式。[17]
